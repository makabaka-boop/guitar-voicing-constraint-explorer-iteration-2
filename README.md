# 指板和弦形状搜索（离线）

一个**纯本地、无网络请求**的指板和弦形状搜索引擎与页面。解决的问题：

> 吉他同一个和弦在指板上能摆出许多音高正确、却超出手指跨度的形状；
> 只匹配音名会把这些根本按不出来的方案排在前面。

本项目对每根弦「闷音 x 或 0–最大品位」的全部组合做**全枚举**，按可演奏性约束过滤，
再按 跨度 → 品位总和 → 形状向量字典序 排序，只展示前 20 个真正按得出来的形状。

此外提供**双和弦切换预演**：选好当前和弦形状与下一和弦目标音级后，在**全部**
合法下一形状（不是单和弦列表的前 20 名）上按
「闷音状态变化弦数 → 两次均发声弦的品位移动量之和」排序，找切换动作最小的下一形状。

## 输入约束

| 输入 | 范围 |
| --- | --- |
| 开放弦 MIDI 音高 | **4–6 根弦**，低音弦 → 高音弦（整数 MIDI） |
| 目标音级 | **2–5 个不同音级**（0=C … 11=B） |
| 最大品位 | **3–9** |

## 一个形状合法的条件

1. 每根弦取 `x`（闷音）或 `0..最大品位`；
2. **弹响弦 ≥ 3 根**；
3. 弹响弦出现的音级**只能来自目标集合**；
4. 且必须**覆盖全部目标音级**；
5. 每根按下的非零品位弦算 1 根手指（**不计横按**），**最多 4 指**；
6. 非零品位的 **最大值 − 最小值 ≤ 4**；没有按弦时跨度算 0。

### 单横按指法模式（可切换，默认关闭）

吉他手常用一根手指横按相邻琴弦，逐弦计指会把本可演奏的横按形状错误淘汰。
开启「单横按指法模式」后，对每个满足音级、响弦与品位跨度规则的形状
枚举**零次或一次横按**的全部指法：

- 横按占 1 指，覆盖一段相邻琴弦，且段内**至少两弦**最终品位恰为横按的正品位；
- 段内不得有闷音、空弦或低于横按品位的弦；
- 段内按更高品位的弦仍需另用手指；横按段外的非零品位也各占 1 指。

先取所需手指数最少的指法；并列时无横按优先，其次按横按品位、起止弦下标升序裁决。
只有最少手指数 ≤ 4 才放行。排序键（跨度 → 品位总和 → 形状向量）不变，
同一形状不会因多种指法重复展示；结果列表、排除原因、自定义形状解释与
SVG 横按标记共用同一份指法结论。该模式下排除判定顺序为
响弦 → 目标外音 → 覆盖 → 跨度 → 最优指法手指数；**默认关闭时一切行为与计数逐项不变**。

## 排序（决定「按得出来」的优先级）

```
跨度(span)  →  品位总和(fretSum)  →  自低音弦到高音弦的形状向量字典序
```

字典序中**闷音 x 排在所有品位之后**（同一位置：`0 < 1 < … < 9 < x`）。
只返回前 **20** 个结果。

## 双和弦切换预演

给定起点形状（点击任一单和弦结果锚定为「当前形状」）与**下一和弦目标音级**，
沿用当前定弦、最大品位、响弦、跨度与单横按约束，对**全部合法下一形状**独立排序：

```
闷音状态变化弦数(x ↔ 发声)  →  两次均发声弦的品位移动量之和
  →  下一形状跨度  →  品位总和  →  形状向量字典序
```

- **闷音状态变化弦数**：逐弦比较，闷音 x 与发声之间切换的弦数越少越好；
- **品位移动量**：仅累加两次**都发声**的弦的 `|from − to|`；
  涉及闷音的弦其动作已计入第一键，不再计品位移动；
- 前两键并列时才沿用单和弦的 跨度 → 品位总和 → 形状向量 兜底。

返回前 **20** 个候选，并给出每个候选的逐弦变化（`起品→新品`，按闷变/移动/不动
着色）；指板 SVG 的「双和弦切换预览」页签下有对应逐弦徽标。实现要点：

- **不截取旧搜索前 20 名再重排**：切换预演与单和弦搜索共用同一个全量枚举器，
  在全部合法形状上分别排序（`enumerateChords`，不截断）；
- 下一形状的**合法性与横按结论由现有指法判定负责**：候选直接携带枚举产出的
  `ChordResult`（含 `bestFingering` 的横按结论），结果列表与 SVG 共用同一份，
  不各自重算；
- 起点形状只需结构合法；若它因**定弦、指法模式或输入编辑**变得不再合法
  （由 `evaluateShape` 对当前约束判定），**撤销切换预演但保留单和弦功能**，
  面板会提示失效原因；
- 没有任何合法下一形状时明确显示**空结果**（合法 0 个、候选为空）。

## 页面功能

- 左侧：定弦预设（标准吉他 / Drop D / DADGAD / 开放 G / 4–5 弦贝斯 / 尤克里里 / 曼陀林）、
  逐弦 MIDI 编辑、根音 + 和弦性质快速设置、12 音级点选、最大品位、升/降号音名切换、
  **单横按指法模式**开关；
- 右上：**指板 SVG 预览**任一结果（弦横向分列、低音弦在左且更粗，按弦为实点、
  开放为空心圆、闷音为 X、横按为跨弦圆角横杠；命中目标的位置有微光提示）；
- **自定义形状模式**：直接点击指板按弦/闷音，实时解释该形状为何合法或**被哪条规则排除**
  （含出现的目标外音级、尚缺的目标音级）；
- 右中：前 20 个结果的品位向量与跨度/总和/指数，点击即在指板预览；
- **双和弦切换预演**：点击结果锚定当前形状，选下一和弦目标音级后展示切换代价最小的
  前 20 个合法下一形状（闷变弦数 → 共同发声移动量 → 跨度/总和/向量排序）、
  逐弦变化与指板切换标记；起点失效时撤销预演、无合法下一形状时显示空结果；
- 右下：五类**排除原因的方案计数**（响弦不足 / 目标外音 / 未覆盖 / 超 4 指 / 跨度过大），
  合法方案与各排除类互不重叠，合计等于总枚举数 `(maxFret+2)^弦数`。

## 技术与目录

原生 TypeScript，无运行时框架；Vite 构建，Vitest 测试：

```
src/search.ts        搜索引擎核心（纯函数，可被任意宿主复用）
src/fretboard.ts     指板 SVG 渲染与点击编辑
src/main.ts          页面交互
test/search.test.ts  Vitest：三弦小样本全枚举对拍 + 移调不变性
test/transition.test.ts  Vitest：双和弦切换预演的小指板全枚举对拍、排序与横按约束
scripts/smoke-dom.mjs 构建产物的 jsdom DOM 冒烟测试
Dockerfile           多阶段构建（node 构建 → nginx:alpine 托管）
docker-compose.yml   fret 服务
```

最坏情况（6 弦 9 品）单和弦枚举 `11^6 = 1,771,561` 个方案，浏览器内约 50ms；
切换预演复用同一次全量枚举，仅多出对合法形状的一遍线性代价计算。

## 本地开发

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest（57 个用例）
npm run build      # 类型检查 + 产出 dist/
npm run smoke      # 对 dist/ 做 jsdom 冒烟（需先 build）
npm run check      # tsc + vitest + build + smoke 全流程
```

构建产物使用相对路径，`dist/index.html` 也可以直接以 `file://` 离线打开。

## Compose 部署（fret 服务）

```bash
docker compose up -d --build
# 页面：http://localhost:8080
```

`fret` 服务是多阶段镜像：Node 构建静态文件，`nginx:1.27-alpine` 在容器内以 8080
端口托管，运行时不访问任何外部地址。

## 测试如何保证正确性

- **三弦小样本全枚举对拍**：`test/search.test.ts` 内含一份独立、直白的笛卡尔积参考实现
  （不剪枝、不共享状态）。在多组 3 弦定弦 × 目标集合 × 最大品位上，核心搜索的
  结果列表、跨度/总和/指数/MIDI、合法总数、五类排除计数、`truncated` 全部与参考逐字段一致；
  并校验「合法 + 各排除 = 总枚举数」，保证每个方案恰好被归入一类。
- **移调不变性**：所有开放弦与目标音级同时平移 k 半音（弦间音程不变）时，
  合法形状的品位向量集合、排序、跨度/手指数/响弦数完全不变，实际发声 MIDI 整体平移 k。
- **单横按指法**：测试内含独立参考实现，在 3/4 弦小指板上对全部形状暴力枚举
  横按区间 [起弦, 止弦] × 横按品位，与 `bestFingering` 逐项对拍手指数与横按结论；
  搜索层再用独立参考全枚举对拍结果列表与排除计数。另覆盖无横按兼容
  （默认合法形状全部保留且相对顺序不变）、闷音/空弦/低品位阻断横按区间、
  并列指法裁决（品位 → 起止弦下标）、形状不重复展示等用例。
- 另含排序键、闷音字典序、零按弦跨度、输入校验（4–6 弦 / 2–5 音级 / 3–9 品）等用例。
- **双和弦切换预演**：`test/transition.test.ts` 内含独立的笛卡尔积参考实现
  （含横按指法参考），在 3/4 弦小指板上对全部「起点形状 × 下一合法形状」组合，
  对拍候选形状序列、闷变弦数、共同发声移动量、逐弦变化、`fingers/barre`、
  合法总数与 `truncated`；另覆盖排序键层级、形状向量兜底、
  **不先截旧搜索前 20 名**（零代价候选可落在单和弦 20 名之外）、
  limit/截断、空结果、参数校验、移调不变性与单横按约束。
  `scripts/smoke-dom.mjs` 的页面冒烟核对切换标记（逐弦变化格、指板徽标）、
  横按锚点随模式关闭而失效、改定弦后撤销预演但单和弦仍可用、以及空结果展示。
